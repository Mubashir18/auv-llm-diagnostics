\# Project 2600: LLM diagnostic agent for AUV telemetry (prototype, Role B)



Prototype of the diagnostic agent: monitoring summary -> RAG + local LLM (Mistral 7B via Ollama) -> JSON diagnosis.

All data is synthetic and generated by the scripts in `src/`. See `docs/STATUS.md` for results and limitations.



\## Setup

1\. Install Ollama and run `ollama pull mistral`

2\. `python -m venv .venv` and activate it

3\. `pip install -r requirements.txt`



\## Run (from the repo root)

python src/gen\_logs.py        # easy synthetic logs

python src/gen\_hard.py        # dev set (h)

python src/gen\_test.py        # test set (t)

python src/monitor.py         # logs -> summaries

python src/rag.py             # builds the reference documents and Chroma index

python src/evaluate.py --labels data/labels\_test.csv --results data/results\_test.jsonl --per-class 10

python src/tune\_baseline.py   # threshold baseline



Note: CPU-only inference takes about 45 s per diagnosis.
